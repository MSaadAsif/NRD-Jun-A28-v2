Thirty-Day Readmission After Coronary Artery Bypass Grafting in Patients With Obesity: A Nationwide Analysis

RCOP NRD A28 — rebuilt analysis (v2), Nationwide Readmissions Database 2016–2017

Preamble

Objective. To estimate the national 30-day all-cause readmission rate after coronary artery bypass grafting (CABG) in adults with obesity, to describe in-hospital complications and resource use at the index and readmission hospitalizations, to identify the causes of readmission, and to identify independent predictors of readmission.

Data source. Retrospective cohort study using the 2016 and 2017 Nationwide Readmissions Database (NRD), sponsored by the Agency for Healthcare Research and Quality’s Healthcare Cost and Utilization Project (HCUP). The NRD is a nationally representative, all-payer database of U.S. hospital discharges that permits tracking of a patient’s readmissions to any hospital within the same state across a calendar year, using verified patient linkage numbers. Discharge weights, stratum identifiers and hospital clusters supplied with the database were used for all estimates.

Study population

Index hospitalizations were adults (age ≥ 18 years) who underwent CABG and who carried a diagnosis of obesity. Both criteria had to be met.

1. CABG, identified by ICD-10-PCS code in any procedure field:

Sites bypassed ICD-10-PCS
One coronary artery site 0210xxx
Two sites 0211xxx
Three sites 0212xxx
Four or more sites 0213xxx

The previously submitted methods section stated that CABG was identified by “codes beginning with 0210”, which describes single-vessel bypass only. The code list actually applied covered 0210–0213; the methods text was wrong, not the cohort. The full family is stated here.

2. Obesity, identified by ICD-10-CM code in any diagnosis field: E66.0x, E66.1, E66.2, E66.8x, E66.9 (obesity), or Z68.3x/Z68.4x (body mass index ≥ 30). E66.3 (overweight, BMI 25.0–29.9) is explicitly excluded.

Operative detail (reviewer #2)

Reviewer #2 asked for “the details of surgical procedure, operation time, CPB time, blood loss, ventilation time, pulmonary complication and so on”. The NRD is an administrative discharge database and carries no operative times, no cardiopulmonary bypass duration and no measured blood loss; those variables do not exist in any HCUP product and cannot be recovered. What the ICD-10-PCS code string does carry has been extracted in full and is now reported in Table 1 and used for subgroup analysis:

Obesity class

The previously submitted methods stated that stratification by obesity class was “not feasible, as direct BMI values were not available”. That is incorrect. The ICD-10-CM Z68 code family encodes measured body mass index to within 1 kg/m². Patients were classified as:

  • Class I (BMI 30.0–34.9): Z68.30–Z68.34
  • Class II (BMI 35.0–39.9): Z68.35–Z68.39
  • Class III (BMI ≥ 40): Z68.41–Z68.45, E66.01, E66.2
  • Unspecified: obesity coded without a BMI code

Where more than one band was coded on the same stay the most severe was kept. Sensitivity analysis S6 repeats the class analysis using the Z68 codes alone.

Reviewer #2 noted that only four postoperative factors were presented. Twenty-one individual complications, grouped into six composites, are now reported with their complete code definitions.

On present-on-admission status. The NRD does not carry present-on-admission indicators. The bleeding, infection and wound-complication families above (T81.x, I97.x, J95.x, K91.x, N99.82/N99.84, G97.x, L76.x, M96.x, D78.x) are postprocedural by definition and therefore identify a complication of care regardless of code position. The non-specific complications (sepsis, pneumonia, atrial fibrillation, acute kidney injury, stroke) are recorded on the CABG admission itself and so occurred during that stay, but for these the code cannot distinguish a condition present at admission from one arising after the operation. This is stated as a limitation.

Myocardial infarction. Acute myocardial infarction (I21, I22) coded anywhere on a CABG admission is, in the great majority of cases, the indication for the operation rather than a complication of it. It is therefore reported in Table 1 as an index-admission descriptor and is not a component of the cardiac complication composite. The complication itself is identified by I97.190 (postprocedural myocardial infarction following cardiac surgery) and I97.790 (postprocedural myocardial infarction during cardiac surgery), the two codes to which the ICD-10-CM Alphabetic Index directs “infarct, myocardium, associated with revascularization procedure”. Both are postprocedural by definition and require no present-on-admission field, and both have been valid since 1 October 2015, so they cover 2016–2017 in full. I21.A1 and I21.A9, which would carry a type 2 or type 5 infarction, took effect on 1 October 2017 and exist for only the final quarter of this window; using them would make the rate a function of discharge date, so they are not used and their unavailability is declared. These code titles are non-specific (“other postprocedural cardiac functional disturbances”), and the resulting rate is correspondingly conservative.

Atrial fibrillation. I48 is reported once, in Table 2, as a component of the cardiac complication composite. It was previously reported a second time in Table 1 as a comorbidity, from the identical flag and therefore with identical counts; that duplicate row has been removed. Because the NRD carries no present-on-admission indicator, I48 on a CABG admission cannot be resolved into pre-existing versus new post-operative atrial fibrillation, and the Table 2 row is labelled accordingly.

Denominators

Two nested denominators are used and are never mixed:

  • The surgical cohort is every hospitalization meeting both cohort criteria, including those ending in in-hospital death. All mortality and index-complication figures are computed on this denominator.
  • The index cohort additionally excludes patients who died during the index admission (they are not at risk of readmission) and discharges without a full observable 30-day follow-up window inside the calendar year. All readmission figures are computed on this denominator.

Excluding in-hospital deaths from the readmission denominator is what removes death as a competing risk, rather than leaving it to be modelled (reviewer #4, major comment 2). Cohort attrition at each step is reported in Table 0.

Every column of every rate table names the cohort it is computed on in its own header, not only in the caption. Three automated checks run before the report is assembled and stop the render if they fail: the surgical cohort used by the survey design must equal the count reported in Table 0; the levels of any stratifying variable must sum back to the cohort being stratified; and no reported confidence interval may be narrower than the sample size printed beside it permits under simple random sampling, since a complex survey design can only ever widen an interval.

Outcomes

Primary outcome: all-cause readmission within 30 days of index discharge, identified through the NRD linkage variables in accordance with HCUP methodology. Unplanned (non-elective) readmission is reported as sensitivity analysis S4.

Secondary outcomes. At the index admission: in-hospital mortality, length of stay, total charges and estimated costs, discharge disposition and the complications listed above. At the readmission: in-hospital mortality, length of stay, cost, time from discharge to readmission, and cause of readmission, classified by the AHRQ Clinical Classifications Software Refined (CCSR, v2025.1) inpatient default category of the readmission principal diagnosis and rolled up to CCSR body-system categories.

Statistical analysis

All estimates account for the NRD complex survey design (discharge weights, hospital-level clustering, stratification), so results are nationally representative. Baseline and outcome characteristics are reported as weighted medians (interquartile range) for continuous variables and counts with weighted percentages for categorical variables, compared using design-based Kruskal–Wallis and Rao–Scott chi-square tests.

Independent predictors of 30-day readmission were identified using survey-weighted logistic regression fitted on the entire index cohort, reported as adjusted odds ratios with 95% confidence intervals. A logistic model rather than a time-to-event model is the primary specification because the outcome is defined over a fixed 30-day window, every patient in the index cohort has a full and uncensored 30 days of observable follow-up by construction, and in-hospital deaths are removed from the denominator. With no censoring and no competing event inside the risk set, a proportional-hazards model contributes no information beyond the binary outcome. A survey-weighted Cox model with a Schoenfeld residual test of the proportional-hazards assumption is nevertheless reported as sensitivity analysis S1.

Covariate selection. The primary model uses a fixed, a-priori covariate set: operative descriptors, obesity class, demographic and administrative variables, hospital characteristics, eighteen comorbidities and the six complication composites. Reviewer #2 asked why all factors were entered rather than only those reaching P < 0.20 or P < 0.30 in univariate analysis. That convention is answered on its own terms: Table 4b reports a univariate survey-weighted logistic model for every candidate variable with its joint design-based Wald p-value, and Table 4c reports the multivariable model restricted to variables reaching P < 0.20, side by side with the a-priori model. The a-priori model remains primary, because selecting covariates on the same data used for estimation biases standard errors and p-values downward, and because with this number of events per candidate variable the pre-specified model is estimable without selection. Reporting both settles the question empirically rather than by argument.

Mediators. Length of stay and non-home discharge are excluded from the primary model. Both lie on the causal pathway between an in-hospital complication and readmission, so conditioning on them removes part of the very association the complication terms are meant to capture. They are added in a third model reported in Table 4d so the change is visible rather than assumed. Variance inflation factors from the fully adjusted model are reported alongside it, so attenuation attributable to mediation can be distinguished from instability attributable to collinearity (reviewer #4, major comment 6).

Subgroups. The primary model is refitted within obesity class, operation performed, number of sites bypassed and pump status, with interaction p-values from design-based Wald tests on the pooled model. These analyses are exploratory, are limited to a short pre-specified list of predictors, and are not adjusted for multiple comparisons.

Small cells. Binary covariates whose smallest outcome cell fell below 11 unweighted discharges were dropped from a given model to avoid quasi-complete separation, and every such exclusion is reported in the relevant table footnote. Multi-level variables were never dropped for this reason. Consistent with HCUP data-use guidance, estimates based on fewer than 11 unweighted discharges are suppressed.

Costs and charges. Total charges were converted to estimated hospital costs using HCUP hospital-specific cost-to-charge ratios, and both charges and costs were adjusted to 2017 dollars using the Consumer Price Index (2016 = 240.007; 2017 = 245.120). Both are reported; costs are the preferred measure.

Data availability. The NRD is a restricted-use, licensed database. Data are available from HCUP to investigators who complete the HCUP Data Use Agreement training and purchase the files; the authors are not permitted to redistribute them (reviewer #4, minor comment 3).

Software. R (version 4.5.0 or later; R Foundation for Statistical Computing, Vienna, Austria), with the survey, srvyr, survival and gtsummary packages, and the in-house easyNRD package for cohort construction and readmission linkage.
